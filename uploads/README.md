# Monthly uploads go here

Each month, after CMS refreshes Care Compare, upload **two** files into this folder:

1. **Provider Information** (stars, scores, staffing):
   https://data.cms.gov/provider-data/dataset/4pq5-n9py → Download the CSV.
2. **Health Deficiencies** (the F-tag lists):
   https://data.cms.gov/provider-data/dataset/r5ix-sfxw → Download the CSV.
   This one covers every nursing home in the country, so it's large. If GitHub says it's over 25 MB,
   zip it first (Windows: right-click → Send to → Compressed (zipped) folder; Mac: right-click → Compress)
   and upload the .zip instead.

Then: **Add file → Upload files** (while you're inside this folder), drop the files in, **Commit changes**.
The site rebuilds in about two minutes. Old files can stay; the newest of each is used.
