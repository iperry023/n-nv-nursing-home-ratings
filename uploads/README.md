# Monthly upload goes here

1. Download the CMS **Provider Information** CSV from
   https://data.cms.gov/provider-data/dataset/4pq5-n9py (the whole-country file is fine).
2. In this folder on GitHub: **Add file → Upload files**, drop the CSV in, then **Commit changes**.
3. The site rebuilds itself in about two minutes.

Old files can stay; the build always uses the newest one (by CMS processing date).
Optional: a CMS health citations CSV here will be used for the immediate jeopardy / harm counts.
